# Tests of different skills or variations
General goal is to get the model writing clear and succint chat.

## Clear and intelligible text
AI models, specially in long and complex contexts will often produce "slop". Very hard to read. Requires multiple passes. Confuses and exahusts the reader.
Here we test if the skill produced a more understandable text. 

**This test must be done by a human** other authors have tried to automate this. I believe that would defeat the purpose. Defining structured comunication for humans is harder than defining a programming language. Maybe it is possible, but it is a very hard problem. LLM's kind of went around that problem and started producing text without following a human designed structure of language. Ignoring that and trying to design that structure would not be smart imho.


## Terse, short text without harming quality
Responses should be as short as possible to avoid token expenditure and context bloat. It must however remain intelligible. Caveman skill was very good at token savings, it however introduced poor readabillity and, I suspect, it degraded reasoning as the model reasoning would get polluted by poor language.
